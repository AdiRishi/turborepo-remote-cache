On Cloudflare Workers, configuration comes from Worker bindings, `vars`, and secrets. On all other platforms, it comes from `process.env`. Values are validated per request; invalid or missing required settings return `500` and log `Invalid server configuration: <reason>`.

## S3 variables

Setting `S3_BUCKET` enables [S3-compatible storage](/storage/s3) when no custom adapter and no Cloudflare storage binding (`KV_STORE` / `R2_STORE`) is configured.

<TypeTable
    type={{
        S3_BUCKET: {
            type: 'string',
            required: true,
            description: 'Non-empty bucket name (required when using S3 storage).',
        },
        S3_ENDPOINT: {
            type: 'string (URL)',
            required: true,
            description:
                'S3 API endpoint URL, such as https://s3.us-east-1.amazonaws.com. Only the origin is used.',
        },
        S3_REGION: {
            type: 'string',
            default: 'AWS_REGION → AWS_DEFAULT_REGION → us-east-1',
            description: 'Signing region. Set to auto for Cloudflare R2.',
        },
        S3_ACCESS_KEY_ID: {
            type: 'string',
            default: 'AWS_ACCESS_KEY_ID',
            description: 'Access key ID.',
        },
        S3_SECRET_ACCESS_KEY: {
            type: 'string',
            default: 'AWS_SECRET_ACCESS_KEY',
            description: 'Secret access key.',
        },
        S3_SESSION_TOKEN: {
            type: 'string',
            default: 'AWS_SESSION_TOKEN (with AWS_* keys)',
            description: 'Temporary session token for IAM execution roles.',
        },
        S3_FORCE_PATH_STYLE: {
            type: '"true" | "false"',
            default: '"false"',
            description:
                'Set "true" to address <endpoint>/<bucket> instead of <bucket>.<endpoint> (required by MinIO and most self-hosted S3 stores).',
        },
    }}
/>

`AWS_*` fallbacks are read strictly from the process environment; `~/.aws` profiles and SSO sessions are not loaded.

## HTTP endpoints

| Endpoint                                | Auth         | Description                                                                                  |
| --------------------------------------- | ------------ | -------------------------------------------------------------------------------------------- |
| `GET /`                                 | None         | Serves the [analytics dashboard](/dashboard).                                                |
| `GET /stats`                            | None         | Returns dashboard analytics as JSON ([`/stats` details](/dashboard#read-the-stats-as-json)). |
| `GET /ping`                             | None         | Returns `pong` for uptime and load-balancer health checks.                                   |
| `/v8/artifacts/...`                     | Bearer token | Official Turborepo Remote Cache v8 API. See the [API reference](/api).                       |
| `POST /internal/delete-expired-objects` | Bearer token | Runs artifact expiry on demand ([details](/retention#run-expiry-on-demand)).                 |

CORS headers on `/v8/*` allow browser requests from any origin. Error responses return JSON in the form `{"code":"unauthorized","message":"Missing or invalid bearer token"}`.
