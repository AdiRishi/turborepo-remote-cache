Turborepo reads remote cache settings from environment variables, config files, and CLI flags.

## Variables and keys

<ResponseField name="TURBO_API" type="string (URL)" required>
    Bare server origin (such as `https://cache.example.com`), without a trailing slash or `/v8`.
    Also configurable as `remoteCache.apiUrl` in `turbo.json`.
</ResponseField>

<ResponseField name="TURBO_TOKEN" type="string" required>
    Shared bearer token matching the server's `TURBO_TOKEN` secret. Set via environment variables or
    user config—never commit it in `turbo.json`.
</ResponseField>

<ResponseField name="TURBO_TEAM" type="string">
    Artifact namespace shared across participating machines. Also configurable as
    `remoteCache.teamSlug` in `turbo.json`; provide either `teamSlug` or `teamId`.
</ResponseField>

<ResponseField name="TURBO_TEAMID" type="string">
    Alternative namespace identifier (`turbo` expects team IDs prefixed with `team_`). Also
    configurable as `remoteCache.teamId` in `turbo.json`.
</ResponseField>

<ResponseField name="TURBO_REMOTE_CACHE_SIGNATURE_KEY" type="string">
    Shared HMAC-SHA256 signing key (32+ bytes recommended) required when `remoteCache.signature` is
    `true` in `turbo.json`. See [Artifact signing](/sign-artifacts).
</ResponseField>

## Precedence order

When the same setting is defined in multiple places, the highest-priority source wins:

1. Command-line flags (`--api`, `--token`, `--team`)
2. `TURBO_*` environment variables
3. `.turbo/config.json` in the repository root
4. User configuration written by `turbo login`
5. `turbo.json`

See Turborepo's [configuration reference](https://turborepo.dev/docs/reference/configuration#remotecache) and [system environment variables](https://turborepo.dev/docs/reference/system-environment-variables) for additional options.

## Environment-only setup

If you prefer not to commit `remoteCache` to `turbo.json`, export all three connection variables:

```sh
export TURBO_API='https://cache.example.com'
export TURBO_TOKEN='<your-token>'
export TURBO_TEAM='my-team'
```

## Per-checkout configuration

You can also store settings for a single local checkout in `.turbo/config.json`:

```json .turbo/config.json
{
    "apiUrl": "https://cache.example.com",
    "teamSlug": "my-team",
    "token": "<your-token>"
}
```

Ensure `.turbo` is listed in `.gitignore` so the token is never committed. For team-wide and CI setup (including an interactive config generator), see [Connect Turborepo](/connect-turbo).
