`turbo` only uploads artifacts for tasks it executes; local cache hits stay local. Clear `.turbo/cache` and run a build to populate the remote cache:

```sh
rm -rf .turbo/cache
npm exec -- turbo run build
```

Run the exact same two lines a second time. Clearing `.turbo/cache` simulates a fresh machine, so every hit replays from your server:

```text
   • Remote caching enabled

build: cache hit, replaying logs edf677b2880f0799

  Tasks:    1 successful, 1 total
 Cached:    1 cached, 1 total
   Time:    19ms >>> FULL TURBO
```

If tasks still miss on the second run, check [Builds keep missing](/troubleshooting#builds-keep-missing).
